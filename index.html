💾 Bewaar je spel

of bewaar met een bladwijzer:

  1. Kijk bovenaan je scherm, in de lange balk waar het webadres staat. Klik rechts in die balk op het sterretje ☆.
  2. Er komt een klein venstertje. Zet bij Map de keuze op Bladwijzerbalk en klik op Klaar.
  3. Klaar! Je game staat nu bovenaan je scherm. Klik er later op en alles is er weer: munten, skins, huisdieren en je record.

Meer verzameld? Tik opnieuw op 💾 en doe het sterretje nog een keer.

Wat doen we eigenlijk?
Een bladwijzer is een snelkoppeling in je browser (Chrome, Edge, Safari...). Onze game stopt je munten, skins en alles in die snelkoppeling. Klik je er later op, dan krijg je alles terug.

Op een computer (Chrome, Edge, Firefox):
1. Kijk heel bovenaan je scherm. Daar staat een lange balk met het webadres (het begint met https).
2. Helemaal rechts in die balk zie je een klein sterretje ☆. Klik erop.
3. Er komt een klein venstertje. Bij “Map” kies je “Bladwijzerbalk” (soms heet dat “Favorietenbalk”). Klik op “Klaar”.
4. Zie je nog niets bovenaan? Druk tegelijk op Ctrl + Shift + B (op een Mac: Cmd + Shift + B). Dan verschijnt de balk met je game erin.

Op een iPad of iPhone (Safari):
1. Tik op het vierkantje met het pijltje omhoog (de Deel-knop).
2. Tik op “Voeg bladwijzer toe” en daarna op “Bewaar”.
3. Later: tik op het boekje en kies je game.

Belangrijk: de bladwijzer onthoudt het moment waarop je op het sterretje drukt. Heb je daarna meer munten verzameld? Tik dan weer op 💾 en maak het sterretje opnieuw.

📂 Spel gevonden

💾 Mijn code

Bewaar je spel met een code van 4 tekens: 1 letter en 3 cijfers, bijvoorbeeld V127. Kies zelf een code of neem de code die het spel verzint. Let op: de code werkt op het apparaat en in de browser waar je hem maakt.
